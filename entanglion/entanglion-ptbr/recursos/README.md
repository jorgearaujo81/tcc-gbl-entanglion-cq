# Recursos — Entanglion pt-BR

Esta pasta contém todos os arquivos necessários para **montar e jogar** o Entanglion em português. Os arquivos estão organizados por tipo de material.

> **O que são recursos?** São os arquivos físicos do jogo — tudo que você precisa imprimir ou fabricar para ter uma cópia do Entanglion em mãos.

---

## Conteúdo

```
recursos/
├── livro-de-regras/       Manual de regras em PDF para impressão
├── tabuleiro/             Tabuleiro traduzido para impressão (em produção)

```

## Dicas de impressão

- Imprima os tabuleiros e cartões em **papel cartão (180–300 g/m²)** para maior durabilidade
- **Plastifique os cartões** após recortá-los para facilitar o manuseio
- Para o tabuleiro, a versão **Pôster** é ideal para uso em sala de aula
- As versões **Light** usam menos tinta e são recomendadas para impressões em preto e branco
