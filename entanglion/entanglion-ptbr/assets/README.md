# Guia de Impressão e Montagem do Entanglion

Muitos dos componentes do jogo Entanglion precisam ser impressos, mas há algumas escolhas que você pode fazer sobre como imprimi-los. Além disso, alguns componentes do jogo podem ser comprados ou reaproveitados de outros jogos. Consulte a tabela abaixo para determinar como você montará sua própria cópia do Entanglion.

---

## Componentes para impressão

| Componente | Formato de papel | Observações |
|---|---|---|
| Tabuleiro do jogo, tabuleiros das naves, cartões do motor, cartões de evento quântico, componentes quânticos, tokens de nave, token de taxa de detecção | Carta (8,5"×11"), A4 (21×29,7 cm) ou Pôster (60 cm de largura) | Disponível em versão escura (padrão) e versão clara (economiza tinta) |
| Dados | — | Compre dados d6 e d8 comuns em qualquer loja de jogos |
| Marcadores de nave | — | Podem ser substituídos por peças de outros jogos |

---

## Recomendações de impressão

A maioria dos componentes do Entanglion foi projetada para ser impressa em uma impressora jato de tinta ou laser padrão. No entanto, o papel padrão usado por essas impressoras é um pouco frágil para uso em jogos de tabuleiro. Recomendamos imprimir em papel **cartão (cartolina)** com gramatura entre 180 e 300 g/m² sempre que possível.

### Dicas para melhor resultado

- **Plastifique os cartões** após recortá-los para maior durabilidade e facilidade de manuseio.
- **Imprima o tabuleiro em formato pôster** (A2 ou maior) para melhor visualização, ou cole as folhas A4 lado a lado.
- Use **papel fotográfico brilhante** para os tabuleiros das naves para um visual mais profissional.
- Para os **dados**: use um d6 (dado de 6 faces) roxo para o dado de Centarious e um d8 (dado de 8 faces) amarelo para o dado de Entanglion. Os valores binários (0 e 1) do dado de Centarious podem ser marcados com adesivos sobre os valores 1–6 (três faces com "0" e três faces com "1").

---

## Versão econômica (menos tinta)

Incluímos uma versão de tema claro dos componentes para papel Carta e A4 que usa significativamente menos tinta. Recomendada para escolas e uso em sala de aula.
