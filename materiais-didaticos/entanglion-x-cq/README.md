# Entanglion x Computação Quântica

Este material é um guia didático de apoio ao jogo Entanglion. Ele conecta cada elemento do jogo — cartas de evento e componentes quânticos — à ciência e aos cientistas que os inspiraram.

Foi desenvolvido como parte da pesquisa de TCC sobre o uso do Entanglion no ensino de Computação Quântica em escolas públicas brasileiras.

## Conteúdo

| Arquivo | Descrição |
|---|---|
| [CartasDeEvento.md](CartasDeEvento.md) | As 9 cartas de evento e suas conexões científicas |
| [ComponentesQuanticos.md](ComponentesQuanticos.md) | Os 8 componentes e suas conexões com hardware quântico real |

## Como usar

Recomendamos usar este material **após** jogar o Entanglion, como aprofundamento. Para cada carta ou componente que surgiu durante o jogo, o professor pode usar este guia para explicar o fenômeno científico correspondente.
